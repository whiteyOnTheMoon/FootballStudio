# FootballStudio

Football Stories Studio – webbasierte Produktion englischsprachiger Vereinsdokumentationen.

## Projektziel

Eine geschützte Web-App erzeugt aus einem gewählten Fußballverein eine ca. 8–10-minütige englische Dokumentation samt MP4, Drehbuch, Quellen und Produktionsstatus. Die Architektur wird für sechs Sprachen vorbereitet.

- **Ziel-Domain:** `studio2.ap-pixels.com`
- **Produktphase:** M0 – Planung
- **Roadmap:** `Football Stories Studio / Projektroadmap`, Version 1.0 vom 09.11.2026
- **Arbeitsweise:** Kein technischer Task ohne GitHub-Issue; Änderungen über Branches und Pull Requests.

## Roadmap

M0 Planung und Entscheidungen → M1 Web-App/VPS → M2 erster vollständiger Film → M3 Qualitäts- und Rechtsprüfung → M4 Video-Design → M5 sechs Sprachen → M6 Betrieb und Automatisierung.
